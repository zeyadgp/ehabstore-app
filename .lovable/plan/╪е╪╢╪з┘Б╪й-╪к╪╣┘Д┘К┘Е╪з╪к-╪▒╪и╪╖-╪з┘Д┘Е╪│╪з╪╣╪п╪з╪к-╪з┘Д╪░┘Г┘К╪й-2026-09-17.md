# إضافة تعليمات ربط المساعدات الذكية

## ما سنبنيه

- إضافة صفحة مستقلة بعنوان «ربط المساعد الذكي» داخل المتجر، بنفس الألوان والتنسيق الحاليين.
- عرض رابط خادم المتجر تلقائياً حسب النطاق المفتوح، مع زر نسخ واضح ورسالة نجاح.
- إضافة إرشادات منفصلة خطوة بخطوة لربط ChatGPT وClaude وClaude Code وأي مساعد آخر يدعم MCP.
- إضافة قسم مستقل يشرح تحديث الاتصال بعد نشر تغييرات جديدة لكل مساعد.
- إضافة رابط ظاهر للصفحة في القائمة الجانبية والفوتر، دون تغيير خادم MCP الحالي.

## التفاصيل التقنية

- المسار الجديد: `/connect`.
- توليد الرابط من نطاق الصفحة الحالية وإضافة `/mcp` إليه، دون تثبيت نطاق معين.
- إنشاء رابط Claude الجاهز بأسماء وبيانات معبأة، وأمر Claude Code آمن وقابل للنسخ.
- استخدام عناصر الموقع الحالية، ودعم الجوال والوضع الداكن واتجاه العربية.
- إضافة بيانات عنوان ووصف ومشاركة خاصة بالصفحة.

## التحقق

- التأكد من ظهور الرابط الصحيح وأزرار النسخ.
- اختبار روابط الإعدادات الخارجية وأقسام التعليمات.
- فحص الصفحة على الهاتف وسطح المكتب، ثم التأكد من خلو النسخة من أخطاء التشغيل.
