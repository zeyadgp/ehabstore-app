# إيهاب ستور | Ehab Store

متجر إلكتروني عربي متخصص في منتجات العناية بالبشرة والشعر، المكياج، والعطور.

يحتوي المشروع على واجهة متجر للعملاء ولوحة تحكم إدارية متكاملة لإدارة المنتجات، الطلبات، المخزون، العملاء، التوصيل، الدفع، التسويق، وبرنامج الولاء.

> ملاحظة: الاسم الحالي للمشروع هو **إيهاب ستور**، رغم أن اسم المستودع هو `star-sync-friend`.

## نبذة عن المشروع

إيهاب ستور هو نظام تجارة إلكترونية مخصص للمتاجر العربية، مع دعم كامل لاتجاه الكتابة من اليمين إلى اليسار (RTL)، وتجربة متجاوبة للجوال والكمبيوتر.

يوفر المشروع:

- متجر إلكتروني للعملاء
- إدارة المنتجات والتصنيفات والماركات
- إدارة الطلبات والمخزون
- نظام حسابات للعملاء
- الدفع والتوصيل
- التقييمات والمراجعات
- الكوبونات والخصومات
- برنامج الولاء والإحالات
- التكامل مع WhatsApp
- التكامل مع Meta Pixel وConversions API
- دعم تطبيق PWA
- تجربة مكياج افتراضية باستخدام MediaPipe
- أدوات MCP للتعامل مع بيانات المتجر عبر المساعدات الذكية

## التثبيت

استنسخ المستودع:

```bash
git clone https://github.com/Sadegzeyad/star-sync-friend.git
cd star-sync-friend
```

ثبّت الاعتماديات:

```bash
npm install
```

أنشئ ملف البيئة:

```bash
cp .env.example .env
```

بعد ذلك أضف بيانات Supabase وإعدادات المشروع داخل ملف `.env`.

## متغيرات البيئة

مثال تقريبي:

```env
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=your_publishable_key
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_PUBLISHABLE_KEY=your_publishable_key
VITE_SUPABASE_PROJECT_ID=your-project-id
```

لا تضع مفاتيح الخادم السرية داخل الواجهة الأمامية أو داخل المستودع.
